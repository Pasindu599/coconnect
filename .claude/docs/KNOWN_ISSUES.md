Narrowing this for real means redesigning that feature (e.g. Google Picker API so the user explicitly grants per-file access) — a product/feature decision, not something to change unilaterally while landing auth. Also worth asking: does a labour-hiring marketplace need a general Drive file browser at all, or is this a leftover from an earlier app template? Flagging for a human call rather than guessing. |
